# Charger les attributions initiales dans le graphe

## Description

Charge les attributions initiales 2024 et 2025 depuis le Parquet préparé et les identités titulaires résolues, sans publier les sorties ni compter les modifications comme de nouveaux marchés.

## Requirements

Verify: Sur les entrées locales, l'import répété est idempotent et les comptes de marchés et de titulaires par année correspondent aux entrées retenues, avec les identifiants conservés comme chaînes.
